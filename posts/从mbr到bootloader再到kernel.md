# 对应关系（火箭 vs 操作系统启动）

你可以这样一一对应：

| 火箭系统             | 操作系统启动         |
| -------------------- | -------------------- |
| 一级火箭（点火起飞） | **MBR**        |
| 二级火箭（继续加速） | **bootloader** |
| 三级火箭（入轨运行） | **kernel**     |


> **MBR → bootloader → kernel，这三段之间“怎么在代码层面连接起来”？**

我不讲概念，直接从“你必须写的代码机制”来拆。
