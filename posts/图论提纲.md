## （待巩固）9、最短路算法及其应用

### Dijkstra 的核心是：

for (int round = 0; round < n; round++) {
    int u = -1;

    for (int i = 0; i < n; i++) {
        if (!visited[i] && dist[i] < best) {
            u = i;
        }
    }

    visited[u] = true;

    for (int v = 0; v < n; v++) {
        dist[v] = min(dist[v], dist[u] + w[u][v]);
    }
}

它每次都选当前距离最小的点。

### Bellman-Ford 的核心是：

for (int round = 0; round < n; round++) {
    int u = -1;

    for (int i = 0; i < n; i++) {
        if (!visited[i] && dist[i] < best) {
            u = i;
        }
    }

    visited[u] = true;

    for (int v = 0; v < n; v++) {
        dist[v] = min(dist[v], dist[u] + w[u][v]);
    }
}

Dijkstra：每轮确定一个最近点。
Bellman-Ford：每轮把所有边都松弛一遍。

# 二、树

## 1、树的概念

无圈图

树，连通的无圈图

森林，无圈图

树与森林都是偶图

圈就是“首尾相接的路”，也叫 cycle：从某个顶点出发，沿边走一圈回到原顶点，并且中间顶点不重复。

每一颗非平凡树至少有两片树叶

图G是树当且仅当图G中任意两点都被唯一的路连接

若T是（m，n）树，则有m=n-1

具有k个分支的森林有n-k条边

每一个n阶连通图的边数至少为n-1

树是最小的连通图

任意树𝑇 两个不邻接顶点加一条边后，可得到唯一圈

G是树，如果G的最大度大于等于k，那么G至少有k个一度顶点

只要一组正整数可以排成度数序列，并且总和等于 2(n−1)，那么一定能画出一棵树，使得这棵树每个顶点的度数正好就是这组数

图的顶点的离心率：𝑒 (𝑣) = max{𝑑 (𝑢, 𝑣)|𝑢 ∈ 𝑉 }

图的半径：𝑟 = min{𝑒 (𝑣)|𝑣 ∈ 𝑉 }

图的中心点：离心率等于半径的点

图的中心：中心点的集合

树的中心由一个点或两个相邻点组成
