在本地把代码  **推送（push）到 GitHub 仓库更新** ，一般就是 4 步。你可以把它理解为：

> **修改代码 → 暂存 → 提交 → 推送到远程仓库**

我给你一套最常用、最标准的流程（几乎所有项目都这么干）。
